Daily health check for the "ai trading" project's scheduled trading system, on the box runner. The failure mode this system has shown is SILENT degradation - a run that reports success and wrote nothing - so this catches it within the day. Read-only on the box except through the runner; the only project writes are the mirror copies and the report doc.

HOLIDAY: if US markets were closed today, confirm every trading task reported a holiday skip and nothing exists under C:\ai-trading-state\manifests\<date>\; that is the whole check.

RULES. Paper, absolute: never call place_equity_order, review_equity_order, cancel_equity_order or any option/crypto order tool, not even to preview. Account lock: only the Robinhood account get_accounts marks agentic_allowed=true, resolved at run time, never by nickname. Reading is not trading. Never write code to the box; the only path you write is C:\ai-trading-inputs\<run_id>\. Never edit the scrubber, mirror.py, the runner, the engine clone or C:\ai-trading-state. Do not work around a refusal: exit 1 means no - do not edit inputs to pass, do not run the engine in the sandbox, do not write a book by hand.

STEP 1 - the runner's sheet. create_directory C:\ai-trading-inputs\<date>-health; write manifest.json {"as_of": "<now UTC>", "files": {}}; then
start_process("C:\\ai-trading-runner\\.venv\\Scripts\\python.exe C:\\ai-trading-runner\\engine\\runner\\run.py --slot health --desk all --inputs C:\\ai-trading-inputs\\<date>-health --state C:\\ai-trading-state --mirror C:\\ai-trading-mirror", timeout_ms 300000)
Read outcome.json, then C:\ai-trading-state\health\<date>.json and <date>.md: pass/warn/fail per check (book freshness per desk, coverage rows against the expected 4 PM + 7 sentinel runs, unjudged, shadow gap, commit age, push backlog, mirror age, heartbeat, dead-man record, engine branch/sha, tz database, lock), each with the value and threshold.

STEP 2 - what the runner cannot see. list_triggers: every trading task's last_run today (four scans, four PMs, sentinel, pre-open watch, mirror sync, dead-man, morning brief; the after-hours watch fires at 16:20, so check yesterday's). Not SUCCEEDED or no fired_at today = FAIL; SUCCEEDED only means the session ran - coverage rows are the evidence the engine did. Scan fired_at to finished_at over 45 min WARN, over 90 FAIL. Any claude/health/<date>-*-blocked.md written today = FAIL naming the slot. Two engine_sha values across today's manifests, or a change from yesterday without a promotion note = WARN naming both.

STEP 3 - mirror state back to the project (the dashboard fallback; these are the ONLY project copies now). read_file from C:\ai-trading-state and project_write verbatim: books\swing|pullback|momentum.json -> claude/paper-book[-pullback|-momentum].json; journals\swing|pullback|momentum.json -> claude/pm-journal[-pullback|-momentum].json; journals\watch.json -> claude/pm-watch-journal.json; coverage\pm-coverage.json -> claude/pm-coverage.json; scans\latest.json -> claude/latest-scan.json; scan-index.json and scan-history.json to the same names; today's scans\<run_id>.json -> claude/scans/<run_id>.json. Skip any file whose bytes match yesterday's copy - every write busts the project cache.

STEP 4 - WRITE claude/health/<date>.md: the runner's .md verbatim, a PASS/WARN/FAIL line per step-2 check with evidence, the day's engine_sha, every UNPROTECTED / KILL SWITCH / HOUSE halt / MACRO GATE / EARNINGS / abandoned / refused line from today's journal entries, and a one-paragraph verdict: how many of the eleven expected engine runs actually did work. Append one line to claude/health/index.md: date, pass/warn/fail counts, five-word verdict.

RUNNER UNREACHABLE: retry once; then project_write claude/health/<date>-health-blocked.md with the error and still do steps 2 and 4 from list_triggers and the project copies, marking every box-side check UNKNOWN, never PASS. Desktop Commander down = box dark (docs/runbooks/box-dark.md): say so first.

REPORT: the verdict paragraph. PushNotification ONLY if any check is FAIL: which link broke, what a human should look at. All-pass days get one line and no push.
